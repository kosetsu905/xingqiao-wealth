安全安装redis
1. 创建安装目录
mkdir -p ~/apps/redis
cd ~/apps/redis
2. 下载 Redis
wget https://download.redis.io/releases/redis-7.2.4.tar.gz
3. 解压 Redis 源码
   tar -xzf redis-7.2.4.tar.gz
   cd redis-7.2.4
4. 编译 Redis
   make
5. 编译成功后，Redis 的可执行文件会在当前目录下的 src/ 文件夹中，如：
src/redis-server
src/redis-cli
6. （可选）运行测试（验证编译成功）
make test
7. 启动
   src/redis-server redis-9001.conf
8. 检查 Redis 是否运行
   src/redis-cli -p 9001
9. 查看redis是否已经启动
   ps aux | grep redis-server
10. 链接redis

    src/redis-cli -p 9001

安装mysql
# 1. 更新系统
sudo yum update -y

# 2. 下载并安装 MySQL YUM 仓库
wget https://dev.mysql.com/get/mysql80-community-release-el8-1.noarch.rpm
sudo rpm -ivh mysql80-community-release-el8-1.noarch.rpm

# 3. 导入 MySQL 官方 GPG 公钥（关键步骤！解决你的问题！）
sudo rpm --import https://repo.mysql.com/RPM-GPG-KEY-mysql-2022

# 4. 清理缓存（可选）
sudo yum clean all
sudo yum makecache

# 5. 安装 MySQL Server
sudo yum install mysql-community-server -y

# 6. 启动 MySQL
sudo systemctl start mysqld
sudo systemctl enable mysqld
sudo systemctl restart mysqld

# 7. 查看临时 root 密码并登录配置
sudo grep 'temporary password' /var/log/mysqld.log
mysql -u root -p
