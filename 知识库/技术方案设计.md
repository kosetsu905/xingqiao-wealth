# 行情数据

所有股票最新数据存放redis

产品类别 stock | forex | indices | crypto | future | fund
市场代码 股票包括（HK、SZ、SH、US、SG、JP、TW、IN、TH、DE、MX、MY、TR、ES、NL、GB、ID、VN），外汇（GB），指数（GB），数字币（BA）、期货（US、HK、CN）、基金（US）等
产品代码



一、存储产品数据的Hash Key：
Key格式：data:{productCode}:{marketCode}:{stockCode}
例如：data:stock:US:AAPL
字段：
lastPrice: 最新价
openPrice: 开盘价
closePrice: 收盘价
highPrice: 最高价
lowPrice: 最低价
volume: 成交量
amount: 成交额
changeRate: 涨跌幅
changePrice: 涨跌额


美国股票AAPL的数据更新：
product = 'stock'
region = 'US'
code = 'AAPL'
data = {
'lastPrice': 150.0,
'openPrice': 148.0,
...
}
