## 工程依赖环境
jdk8
开发工具idea
数据库：mysql
nosql：redis
服务发现、配置管理和服务管理平台： nacos

# 启动主要工程 （启动这些工程就满足基本业务）
xingqiao-modules-system   系统模块
xingqiao-auth  认证模块
xingqiao-gateway  网关工程
xingqiao-modules-message   消息工程
xingqiao-modules-file  文件工程

# 前端工程   xingqiao-wealth-web
vue3
node 版本
v22.17.0
启动命令
# 步骤1：清理全局缓存
npm cache clean --force
# 步骤2：删除项目本地依赖
rm -rf node_modules
# 步骤3：重新安装依赖
npm install
# 步骤4：验证缓存状态（可选）
npm cache verify
# 打包
npm run build   # 或 yarn build



# 平台端工程  xingqiao-wealth-admin   master分支

## 进入项目目录
cd xingqiao-wealth-admin

# #安装依赖
npm install

## 建议不要直接使用 cnpm 安装依赖，会有各种诡异的 bug。可以通过如下操作解决 npm 下载速度慢的问题
npm install --registry=https://registry.npmmirror.com

## 启动服务
npm run dev
